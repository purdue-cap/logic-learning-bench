Translated from Microsoft PROSE FlashFill SyGuS SLIA benchmarks (354 files in `sygus/`)
into Delis dual-side string-transformation benchmarks.

Generated by `scripts/gen.py` (batch via `scripts/gen_all.sh`).

Encoding: each constraint becomes one model with three sorts — `PosIn` (input
positions), `PosOut` (output positions), and `Char` (alphabet). Two semantic
relations `Str.SemIn` / `Str.SemOut` mutually express that a Str expression
evaluates to an input or output substring; the constraint pins `Str.SemOut`
at the full output range. `str.at` and `str.substr` use cross-side
disjunction (the inner sub-expression's value can live on either side); the
remaining operators are same-side. Character equality is derived per-position
via `in_char` / `out_char` lookups, replacing the precomputed `substr_match`
table that blew up in earlier iterations.

`int.neg1`, `str.replace`, `int.indexof`, `int.to_int`, and `str.int2str` are
encoded as `false` placeholders in this first cut — they're rare in the
typical PROSE solution shape and adding them is straightforward when needed.

Original SyGuS source for each `NNNN.sl` is recorded in its `(set-info :source ...)` line.
